# CatTech Arena

Небольшой пример сайта на NestJS: каталог котов, авторизация и режим дуэлей с
захватом соперника.

## Запуск

```bash
npm install
npm run start:dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000).
